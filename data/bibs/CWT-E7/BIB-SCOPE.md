## Key principles pulled from the source

1. "Reference links previously provided on this site have been permanently removed to comply with DoD security policies." — the Bib is now just a text list; you must source each reference yourself.
2. If a reference has been updated since exam creation, the updated version applies when scoring. → prefer current editions on disk where the ISBN matches.
3. **PMK (Professional Military Knowledge) is no longer on the NWAE** — it's measured separately via PMK-EE. **Out of scope for this tool** per the prior Bibmaxxing plan.
4. Scope markers used on the Bib:
   - `CHAPTER X, Y` — specific chapters.
   - `SECTION X` — numbered sections / sub-chapters.
   - `ENCLOSURE X` / `ANNEX X` / `APPENDIX X` — doctrine attachments.
   - `STUDY TOPICS ON X` / `STUDY TOPIC ON X` — narrative scope (when chapters aren't discrete).
   - `STUDY EXECUTIVE SUMMARY` — also read the exec summary in addition to named chapters.
