# JP 3-25 — Countering Threat Networks

**Bib study scope:** Chapter 3.

**Source on disk:** `JP-3-25 Countering Threat Networks.pdf`.

## Why this matters {#why}

Countering Threat Networks (CTN) is the joint doctrine for defeating **networked adversaries** — terrorist organizations, insurgent groups, transnational criminal networks, and hybrid state-sponsored actors. Chief-level relevance: cyber operations are a primary CTN instrument, and many cryptologic taskings feed CTN.

## Threat networks defined {#networks}

A **threat network** is a set of interconnected individuals, groups, or entities whose members share a common purpose and cooperate to achieve shared objectives inimical to U.S. interests. Examples:

- Terrorist networks (ISIS-K, AQAP affiliates).
- Transnational criminal organizations (cartels).
- State-sponsored proxy networks (e.g., IRGC-QF network of partner militias).
- Hybrid state-criminal networks (cyber criminal groups with state tolerance or sponsorship).
- Weapons proliferation networks.

### Network characteristics

- **Nodes** — individuals, groups, facilities, or virtual entities.
- **Links** — the relationships between nodes (communication, logistics, command, financial).
- **Nodes + links = network topology.**
- Networks are often **dark** (hidden), **distributed** (no single HQ), **adaptive** (reconfigure under pressure), and **transnational** (cross borders).

## Network types {#network-types}

JP 3-25 distinguishes several network typologies:

| Type | Example | Characteristics |
|---|---|---|
| **Hierarchical** | Traditional terrorist org | Clear leadership, top-down command |
| **Cellular** | Al Qaeda post-2001 | Independent cells, compartmentalized |
| **Hub-and-spoke** | Cartel with boss + lieutenants | Central leader with radiating subordinates |
| **All-channel** | Modern distributed networks | Many-to-many, no central node |
| **Hybrid** | Most real networks | Mix of the above, adapts over time |

Choosing CTN strategy depends on network type — hierarchical is vulnerable to leadership strikes; all-channel requires fragmenting the mesh.

## Isolating the network — Chapter 3 core concept {#isolating}

Classic CTN doctrine emphasizes **isolating the threat network from its sources of power**. This is more effective than targeting individual members because:

- Network is resilient to individual losses.
- Removing individuals often triggers replacement from deeper bench.
- Isolation attacks the system, not symptoms.

### Sources of network power (the "CTN levers")

- **Leadership** — key decision-makers, ideologues.
- **Safe havens** — physical or virtual sanctuaries.
- **Personnel / recruits** — flow of new members.
- **Materiel** — weapons, explosives, dual-use equipment.
- **Financing** — money flows.
- **Communications** — how orders and intel move.
- **Ideology / narrative** — recruitment + retention fuel.
- **External support** — state sponsors, facilitators.
- **Popular support / tolerance** — local communities that shield or tacitly accept.

Each is a lever: reduce it, and the network weakens. Eliminate it, and the network collapses (in theory; in practice, networks adapt).

## F3EAD targeting cycle {#f3ead}

CTN ops frequently use the **F3EAD** targeting cycle (Find, Fix, Finish, Exploit, Analyze, Disseminate) — the intel-driven, network-focused variant of traditional F2T2EA:

| Phase | Activity |
|---|---|
| **Find** | ID the target (node in the network) |
| **Fix** | Locate and track |
| **Finish** | Capture/kill/disrupt |
| **Exploit** | Intel recovery from operation (pocket litter, DOMEX, debrief) |
| **Analyze** | Fuse exploited intel with existing picture |
| **Disseminate** | Share back to force and partners; feeds next Find |

F3EAD is preferred for CTN because each "Finish" generates intelligence that feeds the next "Find" — the targeting cycle becomes a network-dismantling engine.

## Analytical methods {#methods}

### Social Network Analysis (SNA)

Identifying nodes, links, and centrality metrics to find high-value targets and chokepoints:

- **Degree centrality** — node with the most connections.
- **Betweenness centrality** — node that sits on many shortest paths (broker / gateway).
- **Closeness centrality** — node closest to all others.
- **Eigenvector centrality** — node connected to important nodes (like Google's PageRank).

Removing a high-betweenness node can fragment a network more than removing the most-connected node.

### Link analysis

Mapping relationships between entities using tools like i2 Analyst's Notebook, Palantir, or open-source equivalents (Maltego, Gephi).

### Pattern-of-life (POL) analysis

Identifying daily/weekly/monthly behavioral patterns of target individuals to predict future locations/behaviors.

### Communications analysis

- **Traffic analysis** — metadata (who-talks-to-whom, when, how much) without content.
- **Content analysis** — message content, language, sentiment.
- **COMINT exploitation** — technical SIGINT against comm paths.

Traffic analysis alone, absent content, can produce a stunning amount of network insight — this is a staple SIGINT contribution to CTN.

## CTN in the operational framework {#framework}

CTN is a **whole-of-government** effort — DoD is one of several U.S. partners:

- **Military** — intelligence collection, direct action, SOF operations, cyber effects.
- **Intelligence community** — HUMINT, SIGINT, GEOINT focused on the network.
- **Treasury** — financial sanctions (OFAC), anti-money laundering.
- **State** — diplomatic pressure, Foreign Terrorist Organization designations.
- **DOJ / FBI** — investigation and prosecution.
- **DHS** — border and infrastructure defense.
- **Allies and partners** — coordinated international action.

## Cyber's role in CTN {#cyber-role}

Cyber contributes to CTN across multiple vectors:

- **Cyber ISR** — collecting against network communications, facilitators, command channels.
- **Cyber-enabled disruption** — denying adversary C2, financial flows, propaganda outlets.
- **Attribution support** — pinning cyber activity to specific threat actors.
- **Protecting friendly networks** from threat-network targeting (criminal networks often launch cyber attacks).

SIGINT support to CTN is a core CWT mission: identifying threat-network comms, mapping network topology, supporting attribution.

### Cyber-specific threat network mapping

Modern threat networks have **cyber presence** that can be mapped:

- **Infrastructure** — C2 domains, servers, VPN endpoints.
- **Financial** — cryptocurrency wallets, money-movement services.
- **Recruitment** — Telegram channels, online forums, encrypted messaging groups.
- **Propaganda** — websites, social media accounts, content distribution networks.
- **Technical capability** — exploits, malware, operator skill levels.

Each is a node in the cyber layer of the overall network — and each is reachable by cyber capabilities.

## Non-lethal + lethal effects {#effects}

CTN uses the full spectrum:

- **Lethal** — strikes, direct action (SOF, drone strikes).
- **Non-lethal** — cyber disruption, influence ops, law-enforcement action, sanctions.

The goal is proportional, legally-sound effect that reduces the network's capacity. Non-lethal effects often are lower political cost, but produce slower strategic impact.

## Assessment {#assessment}

Unlike kinetic strikes with visible BDA, CTN assessment is hard:

- **Network activity metrics** — did comms, financial flows, or recruitment drop?
- **Key node status** — is the leadership incapacitated, co-opted, replaced?
- **Adversary adaptation** — is the network reconfiguring or fragmenting?
- **Strategic outcomes** — is the network's political-military objective frustrated?

Measures of Performance (MOP) and Measures of Effectiveness (MOE) from JP 5-0 planning framework apply:
- **MOP:** did we hit the target? (Observable action)
- **MOE:** did the target action reduce network capacity? (Observable effect)

Over-focus on MOPs (body count, comms takedowns) can obscure strategic failure (network not degraded, or political conditions worsened).

## Legal and authorities considerations {#legal}

CTN operations touch multiple legal frameworks:

- **Law of Armed Conflict (LOAC)** — governs lethal effects in conflict.
- **Title 10** — military operations including direct action.
- **Title 50** — intelligence operations, covert action.
- **Title 18 / law enforcement** — FBI-led investigations, arrests.
- **AUMF (2001) / §1021 NDAA** — statutory authorization for CT operations against AQ and associated forces.
- **EO 13224** — Treasury's terrorist-financing designation authority.

Navy CWT operators typically execute under Title 10 or Title 50 authority; supporting a CTN target package may involve intelligence that originated under different authorities — chain of custody and authority matters for follow-on actions.

## Exam-testable concepts {#testable}

- What's a threat network? **Interconnected individuals/groups/entities cooperating against U.S. interests.**
- What's the CTN principle? **Isolate the network from its sources of power.**
- Name at least four sources of network power. **Leadership, safe havens, personnel, materiel, financing, communications, ideology, external support, popular support.**
- What's SNA? **Social Network Analysis — quantitative methods to identify key nodes and links.**
- Betweenness centrality measures? **How often a node sits on shortest paths between others — brokers/gateways.**
- Why is network analysis better than targeting individuals? **Networks are resilient; individuals are replaceable; attacking the system, not symptoms, produces lasting effect.**
- How does cyber support CTN? **ISR, disruption of C2/finance/propaganda, attribution, defense against threat-network cyber attacks.**
- What targeting cycle is CTN-specific? **F3EAD — Find, Fix, Finish, Exploit, Analyze, Disseminate.**
- Difference between MOP and MOE? **MOP = action done; MOE = effect achieved.**
- Which statute authorizes Treasury to designate terrorist financiers? **EO 13224.**
- Which 2001 authorization supports military CT ops? **AUMF (2001 Authorization for Use of Military Force).**
